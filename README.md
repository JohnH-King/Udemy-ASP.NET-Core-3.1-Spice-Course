# Udemy ASP.NET Core 3.1 Spice Course
This repository contains my coursework implementation of the **Spice** application from a Udemy ASP.NET Core 3.1 course.
	
## Course Credit
Credit and thanks to **Bhrugen Patel**, the Udemy instructor whose course guided the creation of this project.

## Project Overview
The project is an ASP.NET Core 3.1 MVC web application that demonstrates common restaurant ordering application features, including menu management, shopping cart functionality, order handling, and identity-based user flows.
